FUNCTION HALL BOOKING - Java Servlet + JSP + JDBC (MySQL)

1. Run schema.sql in MySQL.
2. Edit PASS in src/main/java/com/hall/DBUtil.java.
3. Build:   mvn clean package
4. Copy target/hallbooking-1.0.war to Tomcat 9 /webapps folder
   (Tomcat 9 only - it uses javax.servlet).
5. Open: http://localhost:8080/hallbooking-1.0/
